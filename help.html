Navigation Help

Learn how to use the Campus Navigation System

This guide explains how to search locations, use filters, allow live location, select a destination and get road-based directions inside the campus.

Open Campus Map About Project
01

Allow Location Access

When the website opens, a location permission message appears. Click “Allow Location” so the system can detect your current position and use it as the starting point for directions.

02

Search a Building or Department

Click the search icon in the top bar and type a building name, department name, gate, cafe, hostel or other location. Select the correct result from the suggestion list.

03

Use Category Filters

Use filters like All, Academic, Hostels, Cafe, Gate and Parking to show only the type of places you want to view on the campus map.

04

Select a Destination

Click on any building or point of interest. The selected place will be highlighted and its information will appear in the bottom card.

05

Get Directions

After selecting a destination, click the “Get Directions” button. The system will calculate a road-based route from your current location to the selected place.

06

Reset the Map

Use the reset button to clear the selected destination, remove the route and return the map to the full campus view.
