Campus Navigation System

A smarter way to explore and navigate the University of Kashmir Campus

This project is designed to help students, visitors, faculty members and staff easily find departments, buildings, hostels, gates, cafes, parking areas and other important campus locations using an interactive digital map.

Open Campus Map How to Use

Project Aim

The main aim of this Campus Navigation System is to provide an easy, accurate and user-friendly navigation platform for the University of Kashmir. Instead of depending only on generic map services, this system focuses on campus-specific data such as internal roads, departments, academic blocks, hostels and important points of interest.

🎯

Campus-Focused

The map focuses specifically on internal university features that are usually not clearly available in normal map applications.

🧭

Road-Based Directions

The system uses the campus road network to calculate practical routes instead of drawing simple straight lines.

🔎

Easy Search

Users can search by building name, department name, gate, cafe, hostel or other campus categories.

📍

Live Location

With browser location permission, users can get directions from their current position to a selected destination.

Why this project?

Why a dedicated campus map is needed

01

Generic maps often do not show internal campus departments, academic blocks and smaller facilities clearly.

02

New students and visitors may face difficulty locating a specific department, hostel, gate or facility inside a large campus.

03

This system uses custom campus data prepared using GIS tools, making it more suitable for internal university navigation.

Technology Used

The project combines GIS data with web mapping technologies to create an interactive navigation system.

QGIS Leaflet.js GeoJSON HTML CSS JavaScript Dijkstra Algorithm
