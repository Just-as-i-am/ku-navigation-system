Schools & Departments

Find academic buildings, schools and departments inside the campus

This page provides an overview of academic locations that can be searched and explored through the Campus Navigation System. Students and visitors can use the map to locate departments, schools and related academic blocks.

Open Campus Map How to Search
Academic Navigation

Search by department or academic block

In many cases, one building may contain multiple departments or offices. This system is designed to support searching not only by building name, but also by department name, making it easier for users to reach the correct academic location.

🎓

Academic Departments

Search academic departments directly from the map search option and select the correct result to view details.

🏛️

Academic Blocks

Academic buildings are shown on the map with clear styling so users can identify learning and teaching areas.

📚

Libraries

Important study spaces such as libraries can be marked and searched as campus points of interest.

🧪

Labs & Research Areas

Labs and research-related places can be added as dedicated points for easier academic navigation.

🧭

Route to Department

After selecting a department or building, users can get road-based directions from their current location.

🔎

Department Search

The search system can be improved by adding department names inside the GeoJSON data of each building.

How it works

Department-based searching

01

Each building can store a building name and one or more department names inside its properties.

02

When a user searches, the app checks both building names and department names for matching results.

03

The selected building is highlighted on the map and the information card displays its departments and details.

Recommended Data Fields

For better academic search, each building feature should contain clean and consistent property names.
